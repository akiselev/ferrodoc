# Security policy

Ferrodoc v0.2 is pre-release software for hostile-document processing. Please report vulnerabilities privately through GitHub security advisories for `akiselev/ferrodoc`; do not attach sensitive documents to a public issue.

The supported line is v0.2.x from the signed/tagged source history once a release tag exists. Until then, only the current protected `master` commit is eligible for fixes. See `docs/security.md` for trust boundaries, limits, secret handling, and sandbox limitations.
